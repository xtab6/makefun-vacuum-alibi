One line, up to 200 characters: the alibi a robot vacuum gives for the dust it refused to clean — written by a small deterministic program for The Vacuum's Alibi bounty on make.fun. The program writes the line to /output/entry.txt.

## Run it

```sh
python3 main.py
```
